가사 넣기

검색 결과를 누르면 아래 칸에 가사가 들어가요. 못 찾으면 멜론·벅스 등에서 가사를 복사해 붙여넣으세요. 한 줄에 한 소절씩 넣으면 좋아요. 시간이 적힌 LRC 가사([01:23.45] 형식)를 넣으면 싱크가 자동으로 맞춰져요.

홈 화면에 바로가기 만들기

  1. Safari 오른쪽 위 공유 버튼(네모에 위쪽 화살표)을 눌러요.
  2. 목록을 내려 "홈 화면에 추가"를 눌러요.
  3. 이름이 "보컬 코치"인지 확인하고 오른쪽 위 추가를 눌러요.
  4. 홈 화면의 보컬 코치 아이콘을 누르면 주소창 없이 앱처럼 열려요.

홈 화면 앱은 Safari와 기록을 따로 저장해요. 앞으로는 홈 화면 아이콘으로만 여는 게 좋아요.
